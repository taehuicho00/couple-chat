# 우리 둘 — 한국어 ↔ 베트남어 자동 번역 커플 채팅

- 한국어로 보내면 상대는 베트남어로, 베트남어로 보내면 한국어로 보입니다 (연인 말투).
- 말풍선 첫 줄은 읽는 사람의 언어, 둘째 줄은 같은 말의 다른 언어입니다 (설정에서 끌 수 있고, 말풍선을 누르면 그 말풍선만 접거나 펼칩니다).
- 사진 주고받기, 내 이모티콘(얼굴 사진으로 만든 것), 커플 이모티콘 18종, 이모지.
- 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 구조 (전부 무료)
| 부분 | 서비스 |
|---|---|
| 사이트 | GitHub Pages |
| 대화·사진 저장, 익명 로그인 | Firebase (Firestore, Authentication) — 프로젝트 `couple-chat-39ee8` |
| 번역 | Firebase AI Logic → Gemini (`gemini-3.5-flash-lite`, 무료 등급) |
| 번역 보호 | Firebase App Check (reCAPTCHA Enterprise) + 로그인한 사용자만 허용 |

## 디자인
- 두 사람, 두 언어, 두 가지 색: 한국어는 쪽빛, 베트남어는 연꽃색. 언어를 고르면 그 색이 내 색이 되고, 상대 말풍선은 상대 색으로 옅게 칠해집니다.
- 말풍선 둘째 줄은 그 줄이 쓰인 언어의 색으로 표시합니다.
- 글씨: 베트남어는 Be Vietnam Pro, 한글은 고운돋움 (Google Fonts). 못 불러오면 휴대폰 기본 글씨로 보입니다.
- 밝은 화면과 어두운 화면은 휴대폰 설정을 따릅니다.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 채팅 화면 전체 (Firebase 접속 정보 포함) |
| `stickers.js` | 커플 이모티콘(SVG)과 이모지 목록 |
| `packs/*.bin` | 사진 이모티콘 묶음. **암호화된 파일**이라 코드 없이는 열 수 없음 |
| `firestore.rules` | 데이터베이스 보안 규칙 (Firebase 콘솔에 게시됨) |

## 사용법
1. 한 사람이 먼저 사이트를 열고 언어 · 성별 · 이름 · **방 비밀번호(8자 이상)** 를 입력해 들어갑니다.
2. 오른쪽 위 설정 버튼 → **초대 링크 보내기**로 상대에게 링크를 보냅니다. 상대는 링크를 눌러 이름만 입력하면 같은 방으로 들어옵니다 (비밀번호 입력 없음).
   - 링크(`…/couple-chat/#room=방주소`)가 곧 방 열쇠입니다. 상대에게만 보내세요. 링크가 새어 나갔다면 비밀번호를 바꿔 새 방을 만들면 됩니다.
   - 둘 다 같은 비밀번호를 직접 입력해도 됩니다. 다만 한 글자라도 다르면 서로 다른 방이 됩니다 (대소문자·띄어쓰기는 구분하지 않음).
3. 화면 맨 위에 **상대 이름**과 "같은 방에 있어요"가 뜨면 같은 방입니다. "아직 혼자예요"라고 나오면 그 줄을 눌러 초대 링크를 보내세요.
4. 항상 같은 브라우저로 엽니다 (아이폰: Safari 공유 → 홈 화면에 추가 / 안드로이드: Chrome 메뉴 → 홈 화면에 추가).
   - 설정은 브라우저마다 따로 저장됩니다. 메신저 안에서 열린 화면, Safari, 홈 화면 아이콘은 서로 다른 브라우저로 취급돼 처음 설정을 다시 물어봅니다.
   - 브라우저가 바뀌어도 이름 · 언어 · 성별이 같으면 같은 사람으로 보고, 예전에 보낸 메시지는 계속 내 쪽에 표시됩니다.

## 대화 보관
- 대화와 사진은 Firebase(Firestore)에 저장되고, 보안 규칙상 누구도 지울 수 없습니다. 화면 디자인을 바꿔도 대화는 그대로입니다.
- 화면에는 최근 200개부터 보이고, 맨 위의 **이전 대화 더 보기**를 누르면 300개씩 더 불러옵니다.

## 내 이모티콘 (사진 이모티콘)
- 얼굴 사진으로 만든 이모티콘은 암호화된 묶음 파일(`packs/<id>.bin`, AES-256-GCM)로만 올라갑니다.
- 묶음을 여는 코드(`<id>.<열쇠>`)는 저장소에 없고, 방 안(참여자 문서)과 각자 기기에만 저장됩니다.
- 추가 방법: 받은 링크(`…/couple-chat/#pack=코드`)를 열거나, 이모티콘 창 첫 탭(내 이모티콘) 아래 칸에 코드를 붙여넣고 **추가**. 한 사람만 추가하면 같은 방의 상대에게도 자동으로 생깁니다.
- 관리자는 Firebase 콘솔에서 방의 `members/_packs` 문서(`packs` 배열)에 코드를 넣어 둘 수 있습니다. 그러면 그 방에 들어온 모든 기기에 자동으로 보입니다.
- 방 비밀번호를 바꿔 다른 방으로 옮기면 그 방에서 한 번 더 추가해야 합니다.

## 방 설정 문서 (관리자용)
`rooms/<방 ID>/members` 안에서 이름이 `_`로 시작하는 문서는 사람이 아니라 방 설정입니다. 보안 규칙상 앱에서는 만들 수 없고 Firebase 콘솔에서만 만들 수 있습니다.
- `_moved` (`moveTo`: 방 ID): 이 방에 들어온 기기를 다른 방으로 자동으로 옮깁니다 (방 합치기).
- `_packs` (`packs`: 코드 배열): 이 방에 내 이모티콘 묶음을 넣어 둡니다.

## 보안 메모
- 방 ID는 비밀번호의 해시라서, 비밀번호(또는 초대 링크)를 모르면 대화에 접근할 수 없습니다. 길고 추측하기 어렵게 정하세요.
- 초대 링크에는 비밀번호가 아니라 방 ID가 들어 있습니다. 링크를 열어도 바로 방이 바뀌지 않고, 설정 화면에서 입장을 눌러야 들어갑니다.
- 메시지는 삭제·수정이 막혀 있고, 번역 결과만 추가할 수 있습니다.
- 번역(Gemini)은 이 사이트 주소(`taehuicho00.github.io`)에서 온 요청만 허용됩니다. 주소를 바꾸면 reCAPTCHA 키의 도메인도 추가해야 합니다.
- Gemini 무료 등급은 번역할 문장이 구글 제품 개선에 쓰일 수 있습니다 (사진·스티커는 보내지 않음).
